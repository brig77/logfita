# Logfita

---
ATTENTION: this is a project for personal use that I am making public to help anyone out there with the same need and for my own record keeping. I only work on this project sometimes. So any bug or improvement suggestion might not be addressed soon.   
---


A macOS tool used to track the work hours logged in the macOS Calendar. The main idea is to use the mac OS calendar to log work hours and then use this tool to check if the amount of hours is correct and generate time reports based on configurable rules.
